# Lesson Coach Integration

Lesson Coach should prioritize

1. Core Vocabulary

2. Frequently Recycled Vocabulary

3. High-value grammar

4. Communicative functions

Topic vocabulary should only be recommended when corpus evidence supports it.

Words marked **Graduated (K)** remain in all statistics but are excluded from Lesson Coach vocabulary recommendations.
