# Version 3.0

## Date

Project Initialization

---

## Corpus Added

Japanese with Teppei Beginner

Episodes 1–50

---

## Total Corpus

Episodes 1–50

---

## Major Observations

- Structural repetition is consistently high.
- Grammar recycles much more than vocabulary.
- Topics change regularly while discourse remains stable.
- Explanatory spoken Japanese dominates the corpus.
- Recommendation and opinion structures recur heavily.

---

## Vocabulary Changes

Initial lexical database created.

Vocabulary classified into:

- Core Vocabulary
- Frequently Recycled Vocabulary
- Topic Vocabulary
- One-Off Vocabulary

Learner status introduced:

- Unknown
- Learning
- Graduated (K)

---

## Grammar Changes

Established recurring high-priority structures including:

- ～と思う
- ～という
- ～ということ
- ～こと
- ～ので
- ～ように
- quotation structures
- recommendation structures

No evidence yet suggests significant grammar expansion across Episodes 1–50.

---

## Discourse Changes

Strong evidence for recurring discourse patterns:

- explanation
- recommendation
- examples
- giving reasons
- defining
- comparison

Discourse framework appears substantially more stable than vocabulary.

---

## Metric Changes

Initial project metrics established.

Introduced:

- Structural Density Index (SDI)
- Vocabulary Recycling Index (VRI)
- Topic Turnover Rate (TTR)
- Structural Stability
- Communicative Function Coverage (CFC)
- Transition Readiness Score (TRS)
- Native Input Compatibility (NIC)
- Corpus Importance Score (CIS)

Future updates will refine these metrics.

## Lesson Coach Changes

Lesson Coach Version 3.0 adopted.

New coaching philosophy:

- prioritize structural repetition
- emphasize corpus-wide evidence
- ignore vocabulary marked Graduated (K)
- distinguish core vocabulary from topic vocabulary
- coach attention instead of summarizing lessons

---

## Notes

Version 3.0 establishes the baseline methodology for the project.

Future corpus updates should modify conclusions only when supported by additional evidence.

Previous observations should not be discarded unless contradicted by stronger evidence.
