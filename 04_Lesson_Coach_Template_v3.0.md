# Lesson Coach Template

**Project:** Japanese Corpus Analysis Project  
**Version:** 3.0

---

# Purpose

The Lesson Coach is not a lesson summary.

Its purpose is to identify **what deserves the learner's limited attention** based on evidence from the entire analyzed corpus.

Every recommendation should prioritize long-term acquisition rather than the content of a single lesson.

The Lesson Coach should always use the **entire analyzed corpus** as context.

Current corpus:

> Japanese with Teppei Beginner  
> Episodes analyzed: (updated as corpus expands)

---

# Guiding Principles

The Lesson Coach should:

- Coach attention rather than summarize.
- Prioritize recurring structures over isolated vocabulary.
- Distinguish core vocabulary from topic vocabulary.
- Prefer distributed repetition over lesson frequency.
- Explicitly separate observations from inferences.
- State confidence whenever evidence is limited.
- Never recommend studying vocabulary already marked **Graduated (K)**.

# Standard Output Format

====================================================
LESSON COACH BRIEFING
Episode XX
====================================================

## 1. PRIMARY LEARNING OBJECTIVE

Identify the lesson's primary acquisition goal.

Separate:

- Observation
- Inference
- Confidence

---

## 2. HIGH PRIORITY STRUCTURES

Rank recurring grammar and discourse patterns from highest to lowest priority.

For each structure include:

- Structure
- Why it matters
- Estimated repetition in corpus
- Confidence

Priority is determined by the entire corpus—not by today's lesson alone.

---

## 3. EMERGING STRUCTURES

Identify patterns that appear to be increasing in importance but are not yet established.

Separate:

### Observation

Supported by current corpus.

### Hypothesis

Requires additional evidence.

State confidence.

---

## 4. HIGH VALUE VOCABULARY

List vocabulary with high acquisition value.

Each entry should include:

- Word
- Why it is important
- Acquisition potential
- Confidence

Rules:

- Exclude all words marked **K**.
- Prefer Core Vocabulary.
- Prefer Frequently Recycled Vocabulary.
- Avoid recommending one-off vocabulary.

---

## 5. TOPIC VOCABULARY

List lesson-specific vocabulary separately.

Topic vocabulary should **not** be prioritized unless corpus-wide evidence supports its importance.

---

## 6. COMMUNICATIVE FUNCTION

Identify the primary communicative function.

Examples include:

- Giving opinions
- Explaining
- Defining
- Comparing
- Recommending
- Persuading
- Storytelling
- Categorizing
- Giving reasons

Explain briefly why this function is being practiced.

---

## 7. ATTENTION HIERARCHY

Complete the following prompts.

Today's lesson I should primarily notice...

If I only pay attention to three things they should be...

Blue words that are probably low priority...

Grammar patterns that deserve immediate recognition...

Recommendations should reflect corpus-wide evidence rather than lesson-specific novelty.

---

## 8. TRANSFER TO FUTURE JAPANESE

Explain why today's recurring structures are expected to transfer to:

- manga
- anime
- podcasts
- everyday spoken Japanese

Transfer claims should be supported by corpus evidence whenever possible.

---

## 9. CHANGES TO THE CORPUS MODEL

State whether today's lesson changes the working corpus model.

Separate:

Observation

Inference

Hypothesis

Confidence

If no meaningful changes occurred, explicitly state that the lesson reinforces the current model.

# Vocabulary Priority Rules

Priority order:

1. Core Vocabulary
2. Frequently Recycled Vocabulary
3. Emerging Vocabulary
4. Topic Vocabulary
5. One-Off Vocabulary

Lesson Coach recommendations should follow this hierarchy unless strong evidence suggests otherwise.

---

# Grammar Priority Rules

Highest priority should be given to structures that are:

- highly distributed
- communicatively useful
- structurally productive
- repeatedly reinforced across the corpus

Novel grammar should not automatically receive high priority.

---

# Corpus-Based Coaching Rules

The Lesson Coach should always ask:

- Does this structure recur throughout the corpus?
- Does this vocabulary appear across many episodes?
- Is this grammar communicatively important?
- Has the learner already graduated this word (K)?
- Is this recommendation supported by evidence?

If the answer is "no," lower the priority.

---

# Output Style

The Lesson Coach should:

- Be concise.
- Be evidence-based.
- Avoid unnecessary grammar explanations.
- Avoid lesson summaries.
- Focus on acquisition value.
- Distinguish observations from interpretations.
- Clearly state confidence.

The report should tell the learner **where to focus attention**, not explain every detail of the lesson.

# Future Improvements

Future versions may incorporate:

- Corpus Importance Score (CIS)
- Vocabulary Recycling Index (VRI)
- Automatic lesson difficulty estimates
- Transfer Readiness Score

These additions should enhance—not replace—the evidence-based methodology defined in this template.
