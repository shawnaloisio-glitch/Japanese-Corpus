# Project Purpose

This project exists to build an evidence-based roadmap for acquiring Japanese through comprehensible input.

Rather than evaluating learning resources by JLPT level, popularity, or intuition, the project analyzes corpora to determine what they are actually likely to teach through repeated exposure.

The emphasis is on:

- structural fluency
- vocabulary acquisition
- discourse patterns
- communicative functions
- transfer to native Japanese

The long-term objective is to compare multiple corpora—including podcasts, manga, anime, and other native materials—to identify which resources provide the highest learning yield.

# Evidence Philosophy

This project follows an evidence-first methodology.

Every conclusion must be classified as one of four categories.

## Observation

Directly supported by corpus evidence.

Example:

"The structure ～と思う appears repeatedly throughout the corpus."

---

## Inference

Supported by multiple observations but not directly observable.

Example:

"Teppei appears to prioritize structural repetition over vocabulary expansion."

---

## Hypothesis

A plausible explanation requiring additional corpus evidence.

Example:

"Structural fluency acquired from Teppei may transfer well to native Japanese."

---

## Confidence

Every major conclusion receives a confidence rating.

Possible values:

- High
- Moderate
- Low

Confidence should increase only when supported by additional corpus evidence.

---

# Core Project Principles

The project values:

- evidence over intuition
- distributed repetition over raw frequency
- structural fluency over vocabulary counts
- corpus comparison over isolated analysis

Frequency alone is never considered sufficient evidence of learning value.

Vocabulary that appears across many episodes is considered more valuable than vocabulary appearing many times within a single lesson.

# Corpus Update Workflow

When new transcripts are added:

1. Merge new episodes into the existing corpus.
2. Update frequency statistics.
3. Update the lexical database.
4. Recalculate corpus metrics.
5. Evaluate existing hypotheses.
6. Update confidence where warranted.
7. Record all changes in the changelog.
8. Generate Lesson Coach briefings using the updated corpus.

The project should always evolve from the previous corpus rather than restarting.

# Vocabulary Status

Every tracked word has one learner status.

## Unknown

Not yet learned.

---

## Learning

Currently being acquired.

---

## Graduated (K)

The learner has marked the word with **K**.

Graduated words:

- remain part of corpus statistics
- remain part of frequency calculations
- are excluded from Lesson Coach vocabulary recommendations
- remain in the lexical database unless explicitly de-graduated

---

# Lesson Coach Philosophy

Lesson Coach reports should prioritize:

1. recurring grammatical structures

2. recurring discourse patterns

3. high-value vocabulary

4. transferable communicative functions

Topic vocabulary should only be emphasized when supported by corpus-wide evidence.

Lesson Coach reports should use the entire analyzed corpus as context rather than treating each lesson independently.

---

# Long-Term Vision

The completed project should become a searchable evidence-based acquisition database capable of answering questions such as:

- Which words have the highest acquisition value?

- Which grammar patterns deserve the most attention?

- Which corpus provides the greatest structural repetition?

- Which resources transition most smoothly into native Japanese?

- Which vocabulary is truly core versus merely topical?

- Which structures transfer most effectively into manga, anime, and everyday Japanese?
